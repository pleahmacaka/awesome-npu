# Contributing

Thanks for your interest in improving this list.

## Guidelines

- Add real, commercially available NPUs or AI inference accelerators.
- Cite an official vendor page or reputable source for every entry.
- State precision and note whether a compute figure is a boost value.
- List a price only when it is officially disclosed; otherwise use `-`.
- Mark parts that are not standalone products (SoC-integrated or IP that must be built into a host) with `⚠`.
- Keep one product per row and match the existing column format.
- Run `npx awesome-lint` before opening a pull request and make sure it passes.

## How to submit

1. Fork the repository and create a branch.
2. Make your change in `README.md`.
3. Open a pull request with a short description of the addition or fix and the source you used.
